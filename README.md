# Linkedin-Scraper
[Linkedin Scraper Demo](https://drive.google.com/file/d/1okFeP6sXl4GKX20VBoGib4O_h18RQ2pw/view?usp=drive_link)

A Selenium-based scraper that extracts and structures LinkedIn profiles, handling lazy-loaded content, nested experiences, education, skills, and certifications, converting unstructured data into clean hierarchical JSON while demonstrating dynamic DOM handling and modular automation.
